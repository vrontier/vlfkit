# Provenance

Every file under `original/` was taken on 2026-10-25 from the copy of Paul Nicholson's abelian.org website at https://abelian.vvsindia.com/vlfrx-tools/ (downloaded with HTTrack). The original address, http://abelian.org/vlfrx-tools/, no longer answered at that time. Nothing under `original/` has been changed.

`original/vlfrx-tools-0.9p/` is the unpacked content of `original/vlfrx-tools-0.9p.tgz`. The license text in `LICENSE` is copied from the header of the source files (for example `vtlib.c`).
